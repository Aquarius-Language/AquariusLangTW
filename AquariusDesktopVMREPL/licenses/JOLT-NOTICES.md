# Jolt Physics dependencies

The desktop host uses JoltPhysicsSharp 2.19.1 and JoltPhysics.Native 1.0.4.
Both dependencies and the underlying Jolt engine use the MIT license.

- Binding and joltc: https://github.com/amerkoleci/JoltPhysicsSharp/tree/ba2f3068c391d33788d33ebe53dc0ad4f7c15be4
- Engine: https://github.com/jrouwe/JoltPhysics
- `JOLT-BINDING-LICENSE.txt` contains the binding license.
- `JOLT-PHYSICS-LICENSE.txt` contains the native package's engine license.

Keep this licenses directory with published applications and distribute the
NuGet-provided native runtime assets with the desktop host.
