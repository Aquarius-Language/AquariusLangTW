# 星艦遠征

這個完整範例以繁體中文命名全部變數、函式與參數。星艦先尋找 30 以內的質數航點，
再產生費氏航線及平方航線，透過閉包逐站消耗能量，直到能量不足而返航。
預期找到 10 個質數（總和為 129），探訪 4 顆星球後剩餘 3 單位能量。

從儲存庫根目錄執行：

```powershell
dotnet run --project AquariusDesktopVMREPL -- AquariusDesktopVMREPL/examples/starship_expedition/main.aqua
```

`main.aqua` 利用 `目前工作目錄` 找到同資料夾的 `航行工具.aqua`，因此也可從其他目錄
以主程式的絕對路徑執行。`expected-output.txt` 包含完整預期輸出（最後一行是 VM 桌面入口印出的回傳值）。

| 語法 | 範例用途 |
| --- | --- |
| `#`、`## … ##` | 單行及多行註解 |
| `變數`、`=` | 宣告及重新指派；名稱包含中文、底線及數字 |
| 整數、`f`、`d`、字串、`真`、`假` | 儀表、任務名稱及狀態 |
| `+ - * /`、`-值`、括號 | 費氏遞迴、整除判斷、平方與負溫度 |
| `+= -= *= /=`、`++值`、`值++` | 數值型別轉換、能量、船艙及迴圈更新 |
| `< > <= >= == !=`、`! && \|\|` | 航點搜尋、能量評級及任務狀態 |
| `如果`、`否則如果`、`否則` | 執行三種能量評級分支；也用條件運算式取得結語 |
| `迴圈`、`中斷` | 巢狀質數搜尋及提前返航 |
| `函式`、`回傳`、呼叫 | 遞迴、匿名函式、隱式回傳、巢狀閉包及高階函式 |
| `[]`、`{鍵: 值}`、索引 | 空陣列、巢狀資料、五種雜湊鍵及報告查詢 |
| `匯入`、`.` | 載入模組並呼叫中文函式 |

也展示 `印出`、`長度`、`最後一個`、`其餘`、`加入` 及字串串接。
模組呼叫的引數目前在模組作用域求值，因此先用無引數模組函式取得轉換器與評級器，
再於主程式傳入本地資料。作業系統查詢與外部程式執行是額外的桌面內建功能，
可分別參考既有的 `check_os_platform.aqua`、`execute_file.aqua`。

單元測試會執行實際檔案、比對完整輸出與回傳型別／數值，並檢查每個有效 token 類型
都出現在範例中，且每個識別字都使用中文名稱：

```powershell
dotnet test AquariusLangVMTesting --filter FullyQualifiedName~StarshipExpeditionTest
```
