# 星泉姿態觀測站

以繁體中文星泉程式，在桌面與網頁執行相同的 MediaPipe 姿態 ONNX 模型，呈現三十三個人體關鍵點與骨架。選擇「使用圖形加速」時，推論引擎以 `圖形處理器` 偏好自動選用此平台最快的 GPU 後端：Windows／Linux 以 CUDA 版執行環境建置（預設不含；可用 `aqua build ... --onnx-cuda true` 或專案 `aqua.toml` 的 `[onnx] cuda = true` 加入）且有 NVIDIA 顯示卡及 CUDA 13 與 cuDNN 9 時使用 CUDA，Mac 使用 Core ML，其他情況（含網頁）使用 WebGPU；狀態列會顯示實際使用的後端。也可明確選擇中央處理器。影像與模型推論都在本機執行。

將支援姿態推論的最新星泉編譯器完整發佈套件加入 `PATH`，確認可直接執行 `aqua`，再使用 Windows PowerShell 5.1 或更新版本執行：

```powershell
./建置.ps1
./建置.ps1 -驗證圖形加速
# 桌面執行檔加入選用的 NVIDIA CUDA（需含 CUDA 執行環境套件的編譯器）：
./建置.ps1 -CUDA
# 僅建置網頁：
./建置.ps1 -略過桌面
```

桌面執行 `dist/星泉姿態觀測站.exe`；網頁執行 `node 網頁伺服器.mjs` 後開啟顯示的網址。部署至網站時使用 HTTPS。首次點選啟動按鈕會載入模型並請求攝影機權限；停止按鈕會釋放攝影機與模型。桌面攝影機沿用星泉的 FFmpeg 配接器，須讓 `ffmpeg` 可從執行路徑找到。

攝影機提供六百四十乘四百八十的影格，擷取與顯示均保持原始比例，以留邊方式填滿目標尺寸。程式先執行人物偵測，再依臀部中心、身體尺度與方向建立旋轉裁切區域，送入姿態模型。熱圖細化後的關鍵點會還原到原始影格座標，並以自適應濾波降低抖動。連續影格沿用追蹤區域，失去人物時重新偵測；每隔一點五秒也會重新定位，避免裁切區域漂移。人物可以偏離畫面中央或側轉。

可見性及存在機率都必須達到百分之七十五，且關鍵點位於影格內，才顯示骨架。人物信心僅表示模型判斷畫面有人，不代表每個關鍵點同樣準確。多人時追蹤最可信的一人；嚴重遮擋、人物過小或大量身體部位離開畫面時，模型仍可能誤判，建議讓主要身體部位清楚入鏡。

`姿態模型.aqua` 呼叫核心的雙語姿態追蹤介面。像素以影像物件整批傳送；人物偵測解碼、裁切、座標還原與濾波都執行相同的核心 Wasm，無逐像素星泉陣列轉換。`姿態驗證.aqua` 與 `圖形加速驗證.aqua` 使用空白影像驗證模型與空白拒絕，不需要攝影機。建置預設先驗證中央處理器，加入 `-驗證圖形加速` 可要求桌面 WebGPU 驗證。介面分別顯示完整影格處理耗時、模型耗時與實際影格率；完整影格耗時包含擷取、圖片轉換及姿態處理，影格率另包含繪製與排程時間。

`中文介面.aqua` 集中既有繪圖協定識別碼；所有專案宣告、函式呼叫、變數、註解及使用者介面均使用繁體中文，沿用其他星泉專案慣例。

模型來自 OpenCV Zoo 的 [人物偵測](https://github.com/opencv/opencv_zoo/tree/8e2b658d1007864a24cc2cf0e5b4288c74b32584/models/person_detection_mediapipe)與[姿態關鍵點](https://github.com/opencv/opencv_zoo/tree/1f19f821d68288feff2ef5c53993b33da74b1509/models/pose_estimation_mediapipe)，採 Apache 2.0 授權，授權全文保留於 `模型/模型授權.txt`。
