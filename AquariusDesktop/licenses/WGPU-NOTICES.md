# wgpu dependencies

The desktop host uses Silk.NET.WebGPU, Silk.NET.WebGPU.Extensions.WGPU and
Silk.NET.WebGPU.Native.WGPU 2.23.0. The included license texts come from:

- https://github.com/dotnet/Silk.NET/blob/v2.23.0/LICENSE.md
- https://github.com/gfx-rs/wgpu-native/blob/v0.19.4.1/LICENSE.MIT
- https://github.com/gfx-rs/wgpu/blob/87576b7/LICENSE.MIT

Keep this licenses directory with published applications. The native GLFW,
GLAD and stb_image bridge has separate notices in `native/vendor/`; the release
guide includes their distribution steps.
